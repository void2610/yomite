# Unity 7 Alpha 調査レポート（要約版）

## 結論

==今は上げないでください。== 本線は 6.3 LTS のまま 次の候補は 6.7 LTS です。alpha はプロジェクトを複製して触るだけに留めるのが安全です。

## 要点だけ

| 項目 | 内容 |
|---|---|
| 実在するか | 実在。2026-07-21 発表 2026-10-05 に公開 alpha 開始 |
| 最新版 | 7000.0.0a22（2026-11-27 確認） |
| 入手 | Unity Hub の Pre-releases から。誰でも可 |
| 中身 | ほぼ CoreCLR 化のみ。Mono が無くなり Domain Reload も廃止 |
| まだ無いもの | .NET 10 / C# 14 は時期未定。目玉機能の大半は 6.7 LTS 側 |
| 公式の姿勢 | 本番利用は推奨しないと明言 |
| 今後の予定 | 2026-12 に beta / Preview 2027 年 Q1 に正式版 |
| 6.3 LTS | サポートは 2027-12 まで。急ぐ理由なし |

## 触ると壊れうる点

- Built-in Render Pipeline は alpha で開くと真っ黒に描画される
- BinaryFormatter は廃止
- 旧 API（obsolete）は警告でなくエラーになる
- Localization パッケージの alpha での動作は未確認
